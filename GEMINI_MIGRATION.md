**File**: `.env.example`

**File**: `skillmap/settings.py`

## 🚀 How to Migrate

### Step 1: Get Gemini API Key (FREE!)

1. Visit https://makersuite.google.com/app/apikey
2. Sign in with Google account
3. Click "Get API Key"
4. Click "Create API key"
5. Copy your key (starts with `AIza...`)

### Step 2: Update Environment

```bash
# Edit your .env file
nano .env

# Replace this line:
ANTHROPIC_API_KEY=sk-ant-...

# With:
GEMINI_API_KEY=AIzaSy...your-key-here
```

### Step 3: Reinstall Dependencies

```bash
# If using venv
pip install -r requirements.txt

# If using Docker
docker-compose build
docker-compose up -d
```

### Step 4: Test

```bash
# Upload a CV and check if roadmap generates
# Or test directly:
python manage.py shell
```

```python
from roadmap.tasks import generate_roadmap_with_gemini

result = generate_roadmap_with_gemini(
    ['Python', 'Django'],
    [{'skill': 'React.js', 'demand': 45}]
)
print(result)
```

## 🐛 Troubleshooting

### "Invalid API key"
```bash
# Check your .env file
cat .env | grep GEMINI

# Make sure it starts with AIza and has no spaces
```

### "Module not found: google.generativeai"
```bash
pip install google-generativeai==0.3.2
```

### "Rate limit exceeded"
- Free tier: 15 requests/minute
- Wait 60 seconds or upgrade to paid tier
- App automatically retries

### Gemini not working?
Check logs:
```bash
# Docker
docker-compose logs worker

# Local
# Check console output from Celery worker
```
